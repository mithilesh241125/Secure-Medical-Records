  1. Board Member (Highest)
  2. Admin
  3. Doctor
  4. Nurse (Lowest)

Higher-level roles automatically inherit permissions from lower-level roles.

Role Descriptions
Nurse

Nurses have the most limited access, focusing primarily on viewing patient information and medical records. They can view patient lists and details, view medical records, and access the dashboard for basic analytics.

Doctor

Doctors have broader permissions focused on patient care, including all nurse permissions, adding and editing patient information, creating and updating medical records, viewing patient summaries, and exporting patient data.

Admin

Administrators have comprehensive system management permissions, including all doctor permissions, managing user accounts (create, edit, delete), viewing and managing audit logs, monitoring system anomalies, accessing detailed system statistics, and resolving security anomalies.

Board Member

Board members have the highest level of access with a focus on oversight, including all admin permissions except user management, viewing decrypted medical record data, accessing comprehensive analytics, and monitoring system integrity.

Security Features
  • Immutable Audit Trails: All user actions are logged with timestamp, user ID, and IP address
  • Data Integrity Verification: Medical records are protected with SHA-256 cryptographic hashing
  • Anomaly Detection: Real-time monitoring for suspicious activities
  • Session Management: Automatic timeout after 30 minutes of inactivity
  • IP Binding: Sessions are bound to IP addresses to prevent hijacking
  • CSRF Protection: All forms are protected against cross-site request forgery
  • Data Encryption: All sensitive medical data is encrypted at rest
  • Role-Based Access Control: Hierarchical permissions based on user roles
